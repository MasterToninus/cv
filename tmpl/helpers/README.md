# Shared Jinja/LaTeX fragments

These fragments are imported by the document templates rather than compiled as standalone CVs.
`section_tmpl.tex` renders the original academic sections.
`academic_macros.tex` supplies dossier blocks; `industry_macros.tex` supplies industry entries and summaries.
`additional_information.tex` shares the optional final/context block between the two academic formats.

See [template contracts](../../docs/templates.md) for inputs, macros, and Jinja delimiters.
The [build guide](../../docs/build.md) explains generation and compilation.
