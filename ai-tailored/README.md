# AI-assisted application documents

Standalone CVs, publication lists, bibliographies, and scientific portfolios adapted for particular applications. They are independent of the generated outputs.

Use the [naming convention](../AGENTS.md#ai-document-filenames-and-versions): `YYYY-<Type>-Tony-<Target>[-<Role>][-Draft].tex`. A draft suffix indicates pending review; compilation alone does not establish approval.

Start each new adaptation from the [fresh-generation workflow](../AGENTS.md#tailoring-a-cv-for-a-position). Keep PDFs and auxiliary files in `build/`, substantive notes in [`docs/ai-tailored/`](../docs/ai-tailored/README.md), and provenance records in [`docs/AI-policy-disclosure/`](../docs/AI-policy-disclosure/README.md).

See [standalone compilation](../docs/build.md#standalone-documents) and [author-confirmed data](../docs/confirmed-data.md) before reusing a variant.
