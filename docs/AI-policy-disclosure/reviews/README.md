# Application review folders

Each subfolder groups the existing CV or publication-list review for a particular application.
The records distinguish drafts, recorded approvals, verification limits, and historical source fingerprints.
Ignored PDF outputs and context in other local repositories are described as references, not public attachments.
These records do not establish the status of later versions.
